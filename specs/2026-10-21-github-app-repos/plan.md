# Plan: GitHub App install + `GET /repos`

## 1. GitHub client package (`agentic_github`)
- [ ] Add `packages/github` (`pyproject.toml`, `src/agentic_github/__init__.py`, `py.typed`) to the uv workspace.
- [ ] Add the `githubkit` dependency, and `respx` as a dev dependency. Run `uv lock`.
- [ ] `config.py`: `GithubAppConfig(app_id, slug, private_key: SecretStr)`.
  - [ ] `GithubAppConfig.from_file(app_id, slug, path)` reads the PEM.
  - [ ] It registers the PEM with the `agentic_secrets` redaction registry.
- [ ] `models.py`: `RepoInfo` and `InstallationInfo` (frozen dataclasses or Pydantic models).
- [ ] `errors.py`: `InstallationNotFound` and `GithubApiError`. Their messages carry no token or headers.
- [ ] `app.py`: `GithubApp`, one `githubkit.GitHub(AppAuthStrategy(...))`.
  - [ ] `get_installation(id)`.
  - [ ] `list_repos(id)`: an installation client via `with_auth(auth.as_installation(id))`, `rest.paginate` over the repos accessible to the installation.
  - [ ] `aclose()`.
- [ ] Tests (`packages/github/tests`), with a test RSA key generated by `cryptography` and GitHub mocked by respx:
  - [ ] The JWT is sent to `/app/installations/{id}`.
  - [ ] The token is fetched once and reused across two `list_repos` calls.
  - [ ] Pagination over 2 pages.
  - [ ] A 404 maps to `InstallationNotFound`; 403 and 500 map to `GithubApiError`.
  - [ ] The PEM is redacted in log output.

## 3. API: install flow and repos
- [ ] `settings.py`: `github_app_id`, `github_app_slug`, `github_app_private_key_file`, `web_base_url`.
- [ ] `app.py` lifespan: build a `GithubApp` when all the settings are set and store it on `app.state.github`; close it on shutdown.
- [ ] New `agentic_api/github/` router.
  - [ ] `POST /workspaces/{id}/connections/github/install`:
    - [ ] It stores `github:state:<token>` with the workspace id in Redis (`SET NX EX 600`).
    - [ ] It returns `install_url`.
  - [ ] `GET /github/setup`:
    - [ ] `GETDEL` the state, verify the installation, store the connection.
    - [ ] Redirect with a 303 to `/settings?github=connected` or `?github=error&reason=state|installation|pending`.
  - [ ] `GET /workspaces/{id}/repos`: 404, 409 `no_connection` or `installation_gone`, 502, 503 when not configured.
  - [ ] `DELETE /workspaces/{id}/connections/github`.
- [ ] Extend `ConnectionOut` with `account_login`. Keep the Claude routes unchanged.
- [ ] Tests (`packages/api/tests/test_github.py`), with `GithubApp` replaced by a fake or by respx, and Redis from the existing test fixtures:
  - [ ] The install URL contains the slug and a state.
  - [ ] Setup with a valid state stores the connection and redirects to `connected`.
  - [ ] A reused or expired state, or an unknown installation, redirects with `error`.
  - [ ] `setup_action=request` redirects with `pending`.
  - [ ] Repos are sorted and have the right shape.
  - [ ] Each error code: 404, 409 `no_connection`, 409 `installation_gone`, 502, 503.
  - [ ] Error bodies contain no token.
